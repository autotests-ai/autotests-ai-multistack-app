# JavaScript frontends

| Path | Role |
|------|------|
| `frontend-javascript-react/` | Product UI — JS + React (slot) |
| `frontend-javascript-react/src/test/` | Vitest + RTL for JS React (slot) |
| `frontend-javascript-angular/` | Product UI — JS + Angular (slot; prefer TS Angular) |
| `frontend-javascript-angular/src/test/` | Angular component tests (slot) |
| `frontend-javascript-vue/` | Product UI — JS + Vue (slot) |
| `frontend-javascript-vue/src/test/` | Vue component tests (slot) |
| `frontend-javascript-jquery/` | Product UI — JS + jQuery (slot) |
| `frontend-javascript-vanilla/` | Product UI — vanilla JS pages (active) |

Shared embed / lean runtime live under `frontend/_shared/` — not product URLs.

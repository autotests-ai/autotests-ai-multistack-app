# TypeScript frontends

| Path | Role |
|------|------|
| `frontend-typescript-react/` | Product UI — TS + React (same product as JS React) |
| `frontend-typescript-react/src/test/` | Vitest + RTL (`component_rtl`) |
| `frontend-typescript-angular/` | Product UI — TS + Angular (slot) |
| `frontend-typescript-angular/src/test/` | Angular component tests (slot) |
| `frontend-typescript-vue/` | Product UI — TS + Vue 3 (same product as React) |
| `frontend-typescript-vue/src/test/` | Vitest + Testing Library (`component_vue`) |
| `frontend-typescript-jquery/` | Product UI — TS + jQuery (slot) |
| `frontend-typescript-vanilla/` | Product UI — vanilla TS (slot) |

Component tests live inside the product module (`src/test/`), like backend unit tests.

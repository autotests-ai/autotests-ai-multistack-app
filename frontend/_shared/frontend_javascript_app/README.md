# frontend_javascript_app

Lean design-system runtime used by the vanilla product UI (header + form CSS).

SSOT for assets that Spring materializes into `backend/.../static` at build time via
`backend/scripts/sync-app-static.sh`. Product pages live in
`frontend/javascript/vanilla/frontend_javascript_vanilla/`.

Refresh from monorepo design-system (optional):

```bash
# after wire-ui / DS change — copy the allowlist files here, then sync-app-static
```
